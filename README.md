## Compile and Run

Each activity is intentionally self-contained. Open a terminal in the folder containing the Java file, then run:

```bash
javac FileName.java
java ClassName
```

Example for Exercise 1:

```bash
cd 02_Array_Exercises/Exercise_01_Array_Sorting
javac Exercise1.java
java Exercise1
```
